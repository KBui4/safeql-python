To set up project:
1. Create a new file called .env.
2. Copy all text from .env.template to .env.
3. Fill out .env file with your local database configurations.
4. Create a virtual environment .venv with Python 3.12: `py -3.12 -m venv .venv`.
5. Activate the virtual environment.
6. Install packages from requirements.txt with `pip install -r requirements.txt`.
7. Run main.py with `python main.py`.
